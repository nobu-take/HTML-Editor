HTML Editor for Email

使い方

HTMLメールの本文を作るためのエディタです。登録もログインも要りません。書いた内容はお使いのブラウザの中だけに残り、どこにも送られません。

01はじめに

このエディタが作るのは、メールの本文になるHTMLです。メールを送る機能はありません。出来上がった本文を、普段お使いのメールソフトに渡して送っていただく形になります。

メールのHTMLは、Webページとは書き方が違います。受信側のソフトによって使える書き方が大きく制限されるためです。このエディタが作るHTMLは、はじめからその制限に合わせてあります。

  • レイアウトは表組み（table）で組む
  • 装飾はすべてタグに直接書く
  • 本文の幅は600px
  • 画像には必ず代替テキストを付ける

この4つは、多くのメールソフトで崩れないための最低条件です。テンプレートも部品も、これを守って作ってあります。

保存先はこのブラウザの中です。サーバーはありません。書いた内容が外に出ていないことは、ブラウザの開発者ツールでネットワークを見れば確認できます。そのかわり、別の端末や別のブラウザからは見えません。

02画面の見かた

画面は3つに分かれています。

場所役割
左原稿の一覧。作業中 と 保管 の2つに分かれています
中央編集する場所。プレビューかコード、または両方を並べて表示します
右選んでいる部分の設定。文字の大きさ、色、余白などを変えられます

3つの表示を切り替える

上部の プレビュー / コード /プレビュー ＋ コード で切り替えます。

  • プレビュー — 完成した見た目のまま、文字を直接書き換えられます。ふだんはこれで足ります
  • コード — HTMLをそのまま書き換えます
  • プレビュー ＋ コード — 並べて表示します。片方を直すともう片方に反映されます

表示を広くする

左の一覧や右の設定は畳めます。画面が狭いときは、右上のアプリ全体の表示サイズ で 小さめ を選ぶと、一度に見える範囲が広がります。メールの見た目は変わりません。アプリ側の表示だけが変わります。

03最初の一通

ひととおりの流れです。

  1. テンプレートを選ぶ

    上部の テンプレートから作成 を押します。34件が6つの分類に並びます。用途がいちばん近いものを選んでください。

  2. 見た目を決める

    テンプレート一覧の上に 配色 と 差し色 が並んでいます。先に見た目を決めてから選ぶと早く決まります。一覧のサムネイルがその場で変わります。

  3. 文字を書き換える

    プレビューの文字をクリックすると、その場で書き換えられます。見出し、本文、ボタンの文言、どれも同じ操作です。

  4. 署名を入れる

    末尾に差出人の情報を入れます。登録しておくと選ぶだけで入ります。

  5. 保存する

    保存 または Ctrl + S。左の 作業中 に並びます。

  6. メールにする

    メールにする を押して 本文をコピー、続けて Gmailを開く か Outlookを開く。開いた下書きに貼り付けます。詳しくはこちら。

04テンプレートと見た目

テンプレートは34件。分類は6つです。

分類入っているもの
基本お知らせ、プレーン、白紙
告知・案内ボタン付き、ヘッダー画像、イベント案内、ニュースレターなど
取引・通知注文確認、発送通知、パスワード再設定など
依頼資料送付、日程調整、アンケート依頼など
社内社内連絡、議事録、対応依頼
Webページメールではなくページとして書き出すもの

見た目は5つのジャンルから

ジャンルを変えると、色だけでなく組み方が変わります。見出しの扱い、ボタンの形と幅、行間、余白、区切り線、書体、段組み、要素の並び順まで変わります。

ジャンル向くもの差し色
ビジネス取引先や社外への通常の連絡青・紺・緑・灰
フォーマル案内状、式典、格式のいる場面紺・深緑・臙脂・墨
カジュアル親しい相手、社内、軽い案内橙・青緑・桃・菫
ポップキャンペーン、募集、目を引かせたいもの桃・橙・青・緑・紫
ミニマル装飾を避けたい通知、事務的な連絡黒・灰

34件 × 19通りの配色で、646通りの見た目になります。一覧を646件に増やしていないのは、そのほうが探しやすいためです。先に見た目を決めてから、34件の中から選んでください。

自分のテンプレートにする

よく使う形が決まったら、その原稿を開いた状態でテンプレート画面のいまの内容を登録 を押します。次からは一覧の先頭に出ます。同じ名前で登録すると中身が入れ替わります。

05直す

プレビューの上で直す

文字をクリックすると、その場で書き換えられます。範囲を選ぶと、上に太字・斜体・下線・箇条書き・見出しなどが出ます。

要素の枠をクリックすると、その要素が選ばれます。選ばれている間は、右側にその要素の設定が出ます。ひとつ上へ移動 /ひとつ下へ移動 で並び順を変えられます。

使える書体は限られています。右側の書体の一覧には、メールで確実に表示されるものだけを並べてあります。凝った書体を指定しても、受信側に無ければ別の書体に置き換わるためです。

部品を足す

10種類の部品を挿し込めます。

見出し / 本文 / ボタン / 画像 / 情報テーブル / 注意ボックス /区切り線 / 余白 / 2カラム / 署名

挿し込む位置は、選択位置に挿入 か本文の最後に足す から選べます。

画像について

画像はファイルを貼り付けられません。URLで指定してください。

メールでは画像を埋め込む方法がどれも使えません。データとして直接埋め込む書き方はGmailで削られ、クラウドストレージの直リンクも塞がれています。どこかに置いた画像のURLを指定するのが、現状で唯一確実な方法です。

受信側が画像を出さない設定にしていることもあるので、代替テキストは必ず入れてください。画像が出ないときにその文字が表示されます。

コードで直す

コード に切り替えるとHTMLを直接書き換えられます。プレビュー ＋ コード なら、直したそばから結果を確認できます。

本文の幅を変えたいときは、上部の キャンバスサイズ で600px以外も試せます。ただし600pxが事実上の標準で、それより広いと横スクロールが出る環境があります。

06保存のしくみ

原稿は 作業中 と 保管 の2つに分かれています。作りかけを 作業中 に置き、済んだものを 保管 へ移す、という使い方を想定しています。どちらも件数の上限はありません。

版が残ります

保存するたびに、その時点の内容が版として残ります。原稿を選んでこの版を復元 を押すと、その時点に戻せます。AIに書き換えさせて元に戻したくなったときのためのものです。

消えるとき

保存先はこのブラウザの中（localStorage）です。次の場合、原稿は消えます。

  • ブラウザの閲覧データ（Cookieやサイトデータ）を消したとき
  • プライベートウィンドウ／シークレットウィンドウで使い、そのウィンドウを閉じたとき
  • 別の端末、別のブラウザで開いたとき（そちらには最初から入っていません）

残しておきたい原稿は、ファイルに書き出す かWebページとして書き出す で手元に保存してください。

保存できる量にも限りがあります。いっぱいになりそうなときは、古い版から自動的に減らしていきます。原稿そのものが消えることはありません。

07署名

よく使う署名を登録しておくと、選ぶだけで本文の末尾に入ります。登録内容もこのブラウザの中に保存されます。

署名の形は4行を基本にしてあります。

  1. 会社名・部署
  2. 氏名
  3. 住所
  4. 連絡先

住所の行は消さないでください。宣伝や案内のメールを送るとき、差出人の所在地を本文に書くことが法律で求められる国があります（米国のCAN-SPAM法など）。日本国内だけに送る場合も、書いておいて損はありません。

08AIに聞く

このエディタ自体はAIに接続していません。AIに渡すための依頼文を組み立てるところまでを受け持ちます。出来上がった依頼文をコピーして、お使いのAIに貼り付けてください。特定のサービスに限定していません。

  1. 依頼の種類を選ぶ

    9種類あります。文面を考える / 表現を整える / もっと丁寧に / 短くする /見た目を整える / 装飾を足す / HTMLを直す / スマホで読みやすく / 英訳する

  2. 追加の注文を書く

    「若い層向けに」など、伝えたいことがあれば書き添えます。空でも構いません。

  3. プロンプトをコピーする

    プロンプトをコピー を押します。いまの原稿を含めるかどうかも選べます。

  4. AIに貼って、返ってきたHTMLを戻す

    返ってきたHTMLを 全体を置き換える に貼ります。気に入らなければ、保存してある前の版に戻せます。

よく使う依頼は 依頼を登録する で登録しておけます。次からは種類の一覧に並びます。

置き換える前に保存しておいてください。保存しておけば、AIの結果が思ったものと違ってもこの版を復元 で戻せます。

09メールにする

上部の メールにする から、4つの方法を選べます。

GmailやOutlookで送る場合

本文をコピーしてから、貼り付けます。GmailもOutlookも、Web版には出来上がったメールのファイルを読み込む機能がありません。貼り付けが唯一の方法です。

  1. 本文をコピー を押す

    見た目を保ったままコピーされます。

  2. Gmailを開く か Outlookを開く を押す

    新しいタブで下書きが開きます。

  3. 本文の欄に貼り付ける

    Ctrl + V。件名と宛先は、そのまま続けて入力してください。

コピーと「開く」を分けてあるのは、順番が大事だからです。先に別のタブへ移ってしまうと、コピーの操作がしづらくなります。必ずコピーしてから開いてください。

メールソフトで開く場合

ファイルに書き出す を選ぶと、メール形式のファイル（.eml）を保存できます。パソコンのメールソフトに関連付けられていれば、開いて下書きとして使えます。対応はソフトによって異なります。

Webページとして使う場合

Webページとして書き出す を選ぶと、そのまま開けるHTMLファイルとして保存できます。メールではなく、社内の掲示や案内ページに使いたいときに。

11困ったとき

貼り付けても見た目が反映されない

コピーしてから貼り付けるまでの間に、別のところをコピーしていないか確認してください。また、下書きの本文欄に貼り付けているかを確かめてください。件名の欄に貼ると文字だけになります。

原稿が見当たらない

同じブラウザの同じプロファイルで開いているか確認してください。別の端末、別のブラウザ、プライベートウィンドウには入っていません。詳しくは保存のしくみを。

受信側で崩れる

本文の幅を600pxより広げていないか、テンプレートの表組みを崩していないかを確認してください。メールソフトによっては、複雑な組み方をそのまま表示できません。スマホで読みやすく をAIに依頼するのも手です。

言語が思ったものと違う

ブラウザの言語設定に合わせて自動で開きます。切り替えたいときは、右上の言語の一覧から選んでください。いまのところ日本語と英語です。
