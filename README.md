# HTML Editor（独立版）

HTMLメールやお知らせページを、コードを書かずに作るためのエディタです。
**サーバーもデータベースも要りません。** 1枚のHTMLとして動きます。

- プレビュー上で直接クリックして書き換えられます
- テンプレート34件・部品10件が入っています
- 作ったものは HTML / テキスト / `.eml`（メールソフト用）として書き出せます
- 保存先はブラウザの中（localStorage）

---

## 手元で動かす

Node.js があれば動きます。**依存パッケージはありません**（`npm install` は不要）。

```bash
node tools/build.js
```

```bash
node tools/serve.js
```

<http://localhost:8080/> が開きます。

`file://` で直接開かないでください。ブラウザによっては localStorage が
使えず、保存が黙って消えます。確認は必ずサーバー越しに行ってください。

---

## Cloudflare Pages へ置く

`dist/` の中身をそのまま配るだけです。

### 手順

1. **新しいリポジトリを作る**（private を推奨）。既存のサイトとは分けてください。
   同じリポジトリに入れると、片方のコミットでもう片方のビルドが走り、
   アカウント共通の月500デプロイを無駄に消費します。

2. **`dist/` を含めて push します。**
   `.gitignore` は `dist/` を除外していません。**これは意図的です。**
   ビルド済みを置いておけば、Pages 側でビルドが要らなくなります。

3. Cloudflare の **Workers & Pages → 新規 → Pages → Git に接続**。

4. ビルドの設定は**空のまま**にします。

   | 項目 | 値 |
   | --- | --- |
   | フレームワーク プリセット | なし |
   | ビルドコマンド | **空** |
   | ビルド出力ディレクトリ | `dist` |

5. デプロイすると `〜.pages.dev` で開きます。

6. 独自ドメインを使うなら、**カスタムドメインでサブドメインを当てます**
   （例 `editor.あなたのドメイン`）。既存サイトのapexはそのままです。

### 更新するとき

```bash
node tools/build.js
```

`dist/` の変更ごと push すれば、Pages が自動で反映します。

### 中身を自分だけに限りたいとき

Pages のプロジェクトに **Cloudflare Access** をかけると、
指定したメールアドレスでログインした人だけが開けるようになります。
静的サイトは URL を知っていれば誰でも開けるので、
人に見せるつもりが無いうちは掛けておくのが安全です。

## 設定

### `config.json`

```json
{
  "imageBase": "/img/"
}
```

テンプレートに入っている見本画像の置き場です。

- **このサイトの中で使うだけ**なら `/img/` のままで構いません
- **作った原稿をメールとして送る**なら、絶対URLにしてください
  （例 `https://editor.あなたのドメイン/img/`）。
  相対のままだと、受け取った側で画像が出ません

変えたら `node tools/build.js` をやり直してください。

### 見本画像を作り直す

```bash
node tools/make-images.js
```

`assets/img/` に7枚を書き出します。グラデーションと図形だけで
描いているので、外部の素材は使っていません。

## 保存について

保存先は **ブラウザの localStorage** です。性質を理解して使ってください。

| | |
| --- | --- |
| 範囲 | 端末ごと・ブラウザごと。同期しません |
| 消えるとき | 閲覧データ（サイトデータ）を消したとき |
| 容量 | 5MB前後。原稿1件は数十KB程度 |
| 他人から | 見えません。サーバーへは何も送っていません |

**大事な原稿は「書き出す」からHTMLとして手元に落としてください。**
これが唯一の確実なバックアップです。

引き出しは「作業中」と「保管」の2つあります。間でコピー・移動できます。

## 構成

```
src/
  Index.html        画面の骨組み
  Stylesheet.html   見た目
  JavaScript.html   画面の動き（編集・選択・書き出し）
  Templates.js      テンプレート34件と部品10件
  store.js          保存部。localStorage に置く
tools/
  build.js          1枚のHTMLに束ねる
  serve.js          手元で確かめる用のサーバー
  make-images.js    見本画像を作る
assets/img/         見本画像
dist/               ビルド結果。Cloudflare Pages に置くのはここ
```

### 画面と保存部の境目

画面側は `google.script.run` というひとつの窓口しか知りません。
`store.js` がその窓口を作って受けるので、**画面側のコードは1行も
変えずに**保存先だけを差し替えられます。

窓口は28個あります。1つでも欠けると、そこを呼んだ時点で例外になります。
足すときも減らすときも、両側をそろえてください。

```bash
node tools/check-api.js
```

画面が呼ぶ名前と `store.js` が持つ名前を突き合わせます。

### あとから保存先を変えるなら

同じ窓口を Cloudflare Functions などで実装すれば、
端末をまたいだ保存に移せます。差し替えるのは `store.js` だけです。

## 元になったもの

Google Apps Script 上のアプリとして作ったものを、GASへの依存を外して
独立させたものです。画面側はブラウザだけで動いていたので、
ほぼそのまま使っています。

Googleドライブ・Gmail・共有ドライブに依存していた部分は取り除き、
`store.js` と `.eml` の書き出しに置き換えています。
